# Placard

A museum wall label that names a piece: inventory line, title, then medium and date.

- `placard` ground, `placard-ink` text, `shadow-placard`, padding `space-3`, square corners.
- Line 1: mono `placard-label` in `tyrian` (inventory number or room). Line 2: `placard-title`. Line 3: `small` in `placard-muted`.
- The large variant (project detail) adds a 2-column grid of label/value pairs above a hairline and an action button.
- Place it off the frame's lower-right corner; it must never cover the artwork.
- The consumer provides the label, title and medium/date text.
